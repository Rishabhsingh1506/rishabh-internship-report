# Source Notes

## Official Indian agriculture data portals

The Open Government Data (OGD) Platform India publishes agriculture datasets. Relevant examples are:

1. District-wise, season-wise crop production statistics.
2. Current daily price of various commodities from various markets (Mandi).

The repository uses a synthetic market dataset for reproducibility and a small report-aligned annual/rice-wheat dataset for demonstrating the exact analysis themes in the internship report.

Before claiming that the repository contains downloaded official raw data, replace the synthetic file with the official resource and record:
- publisher
- dataset title
- resource URL
- access/download date
- units
- frequency
- transformations
