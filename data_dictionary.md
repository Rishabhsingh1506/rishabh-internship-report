# Data Dictionary

| Field | Type | Unit | Description |
|---|---|---|---|
| Date | Date | YYYY-MM-DD | Observation date |
| State | Category | Text | Indian state |
| District_APMC | Category | Text | District/market identifier |
| Commodity | Category | Text | Agricultural commodity |
| Season | Category | Text | Kharif/Rabi/Zaid |
| Area_ha | Numeric | hectares | Area under crop |
| Production_million_tonnes | Numeric | million tonnes | Crop production |
| Yield_kg_ha | Numeric | kg/ha | Crop yield |
| Min_Price_Rs_quintal | Numeric | Rs/quintal | Minimum wholesale price |
| Modal_Price_Rs_quintal | Numeric | Rs/quintal | Modal wholesale price |
| Max_Price_Rs_quintal | Numeric | Rs/quintal | Maximum wholesale price |
| Arrivals_tonnes | Numeric | tonnes | Market arrivals |
| Source | Text | - | Dataset/source note |

The field design follows the data-dictionary concepts shown in the internship report, including Date, State, District/APMC, Commodity, Area, Production, Yield, Min Price, Modal Price, Max Price, Arrivals and Source.
